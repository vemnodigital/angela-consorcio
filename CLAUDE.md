# Angela Consórcio — Landing Page In Foco Soluções

## Projeto
Landing page da Angela Magalhães (In Foco Soluções, Belo Horizonte/MG) para captação de leads de consórcio e seguros.

## Deploy
- GitHub Pages: https://vemnodigital.github.io/angela-consorcio/
- Repositório: https://github.com/vemnodigital/angela-consorcio
- Publica sozinho a cada push na branch `main`.

## Arquivos publicados
- `index.html` — página (HTML/CSS/JS puro, sem dependências além do Google Fonts)
- `politica-privacidade.html` — Política de Privacidade (LGPD)
- `fotos/` — fotos da página (trocar mantendo o mesmo nome)
- `assets/logo-*.png` — logos In Foco (cabeçalho, rodapé, ícone)

## Fluxo de trabalho
- Editar em `nova_versao/`, validar localmente e só então copiar para a raiz e dar push.
- `uploads/` (originais) e `versoes/` (backup da v4) ficam fora do git.
- Versão antiga (v4 standalone): tag local `v4-standalone` e `versoes/`.
